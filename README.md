## 本机启动

固定地址：http://localhost:8767/ 。双击 `/Users/danielyu/Documents/启动Quick Reminder.command` 会启动本地服务并打开页面；登录 macOS 后也会自动打开。服务仅监听本机 127.0.0.1，日志位于 `~/Library/Logs/InfraStartup/quick-reminder-server.log`。

macOS 登录启动配置及 `.command` 启动器副本存放在 `macos/`，配置中的绝对路径适用于当前电脑。

QUICK REMINDER / DEEP LEARNING

LoRA：rank 与 alpha 分别做什么？

rank 决定低秩支路的容量；alpha 控制这条支路加回原输出时的缩放。

01 计算原理02 Rank03 Alpha04 参数示例05 易混淆点
01 / PRINCIPLE

保留原层，用低秩矩阵表示更新

$$y=Wx+b+\underbrace{\frac{\alpha}{r}BAx}_{\text{LoRA 增量}}.$$

\(W\) 是原始 Linear 的权重；\(A\) 把输入投影到较低维度，\(B\) 再映射到输出维度。LoRA 不要求把已有的 \(W\) 做 SVD 分解，也不缩小原始层；它用 \(BA\) 参数化权重更新。通常冻结 \(W\)，仅训练 \(A\)、\(B\)。

02 / CAPACITY

Rank：决定能学多丰富的更新

若输入、输出维度分别为 \(d_{\mathrm{in}}\)、\(d_{\mathrm{out}}\)，则：

$$A\in\mathbb{R}^{r\times d_{\mathrm{in}}},\qquad B\in\mathbb{R}^{d_{\mathrm{out}}\times r},\qquad \operatorname{rank}(BA)\le\min(r,d_{\mathrm{in}},d_{\mathrm{out}}).$$

\(r\) 是中间维度，也是更新矩阵秩的上限，不是训练后实际秩一定等于它。增大 rank 会增加可学习空间，也增加参数量、训练显存和额外计算；不保证效果一定更好。

$$N_{\mathrm{LoRA}}=r(d_{\mathrm{in}}+d_{\mathrm{out}}),\qquad N_W=d_{\mathrm{in}}d_{\mathrm{out}}.$$

以上仅比较权重参数，忽略 bias。rank 决定参数形状，不能在一个已经训练好的 checkpoint 上随意切换而保持同一套 A/B。

03 / SCALING

Alpha：通过 alpha/r 调整增量幅度

$$\Delta W=\frac{\alpha}{r}BA.$$

在 A/B 权重不变时，alpha 越大，LoRA 增量的幅度越大；alpha 不改变 A/B 的维度或参数量。训练时它也参与缩放支路输出及相关梯度，但它不是学习率。

05 / REMEMBER

下次只需记住这几件事

  • rank 管容量，alpha 管缩放。前者改变参数形状，后者不改变参数量。
  • 同时看 alpha/r。固定 alpha 只改 rank，会同时改变容量和缩放；若希望保持缩放为 1，可令 alpha 跟随 rank。
  • B 零初始化时，增量为零。因此即使缩放是 1，初始输出也仍等于原始 Linear；A 通常随机初始化。
  • LoRA 是权重适配方式，不等于 memory retrieval。是否获得记忆能力取决于训练任务、数据和对应推理流程，单纯挂上 LoRA 不会自动增加记忆检索。
